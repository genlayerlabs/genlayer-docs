# Networks

GenLayer operates as two layers: the **GenLayer RPC** handles intelligent contract operations (`gen_*` methods), while the **GenLayer Chain** is the underlying Arbitrum Orbit L2 that handles standard Ethereum operations (`eth_*` methods). The GenLayer RPC also passes through supported `eth_*` calls to the underlying chain, so you can use either endpoint for standard wallet operations.

For the full RPC reference, see [GenLayer Node API](/api-references/genlayer-node).

For transfers and staking, connect to the **GenLayer Chain RPC**. Intelligent-contract methods such as `gen_call` require a **GenLayer node RPC**; the Conduit chain RPC does not provide them. Use a Phase 2-compatible GenLayer node endpoint for SDK intelligent-contract operations.

The GenLayer Chain WebSocket is `wss://rpc.testnet-chain.genlayer.com` and requires an API key. Create a key at [app.conduit.xyz/rpc-keys](https://app.conduit.xyz/rpc-keys) and configure it as `GENLAYERNODE_ROLLUP_GENLAYERCHAINRPCKEY` in the node environment (or the `.env` next to `docker-compose.yaml`). Never add it to URLs or `config.yaml`. Resolve Staking and ConsensusMain through the AddressManager instead of treating their initial addresses as permanent network identity.

Public domains above are the intended release endpoints. Check their readiness and the faucet's target network before transferring funds; do not assume old balances or registrations carry over.

## Recommended Flow

1. **Start on Studionet** — zero setup, open [studio.genlayer.com](https://studio.genlayer.com)
2. **Use Studio dev only for release-candidate validation** — open [studio-dev.genlayer.com](https://studio-dev.genlayer.com) with the matching RC tooling
3. **Move to Localnet** — when you need full control and fast iteration
4. **Deploy to Bradbury** — when ready for production-like testing with real AI workloads
