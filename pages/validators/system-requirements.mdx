# System Requirements

System Requirements for a GenLayer validator node are the **initial** recommended hardware and software guidelines for running one. These guidelines may change as the network grows and evolves.

## RAM

- **Recommended:** 16 GB
- **Why:**
  - GenLayer's _genvm_ can spawn multiple Sub-VMs for contract calls and non-deterministic blocks.
  - Each Sub-VM can consume up to ~4 GB of RAM for storage.

## Swap

- **Recommended:** 128 GB of swap, in addition to the recommended RAM
- **Why:** Transaction throughput and the resulting memory demand are not yet known, so size swap conservatively to provide headroom for memory spikes
- Monitor RAM and swap usage as network load becomes clearer; sustained swapping can slow transaction execution

## CPU

- **Recommended:** Modern multi-core processor with at least 8 cores/16 threads

## Architecture

- **Recommended:** `AMD64`
- `ARM64` is not supported at this time

## Storage

- **Recommended Disk Space:** 128 GB+ (excluding swap)
- **Preferred Type:** SSD or NVMe (M.2)

## Network

- 100 Mbps connection
- **Recommended:**: 1 Gbps+

## GPU (Optional)

- GPU is **Not Required**
- If you want to run LLMs locally, you will need to select appropriate hardware (typically a CUDA-compatible GPU with sufficient VRAM for the model you intend to use)

<Callout emoji="⚠️">
  These requirements are a starting point. As GenLayer evolves and usage
  patterns change (e.g., more complex AI-driven Intelligent Contracts), the
  recommended hardware may change.
</Callout>

## Software

- Operating System - 64-bit Linux (Ubuntu, Debian, CentOS, etc.)
- `docker` - for running the WebDriver container
- `python3`, `python3-pip` and `python3-venv` for GenVM setup

### musl libc (Recommended on Linux)

We recommend installing musl libc on Linux so GenVM binaries can use their default ELF interpreter path. On Ubuntu or Debian:

```bash copy
sudo apt-get update
sudo apt-get install -y musl
```

For other Linux distributions, install the musl runtime package using your distribution's package manager. Check that the interpreter for your architecture exists and is executable:

| Architecture | Default ELF Interpreter Path |
|--------------|------------------------------|
| AMD64 (`x86_64`) | `/lib/ld-musl-x86_64.so.1` |
| ARM64 (`aarch64`) | `/lib/ld-musl-aarch64.so.1` |

The AArch64 path is provided as a GenVM reference; validator nodes currently support AMD64 only
